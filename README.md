# Paradise Nursery

Paradise Nursery is a responsive plant shop application built with React, Vite, and Redux Toolkit.

## Features
- Landing page with the Paradise Nursery name and Get Started button
- About Us page with company information
- Plant catalogue with category filters
- Add plants to the shopping cart
- Cart quantity controls, remove item, and order total
- Redux Toolkit state management

## Run locally
1. Install [Node.js](https://nodejs.org/).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## Build
Run `npm run build` to create the production build in the `dist` folder.

## GitHub upload
Create a public GitHub repository named `paradise-nursery`. Upload the project files and folders from this ZIP. Do not upload `node_modules` or `dist`.

## Required assignment files
- `README.md`
- `src/components/AboutUs.jsx`
- `src/App.css`
- `src/App.jsx`
- `src/redux/CartSlice.jsx`
